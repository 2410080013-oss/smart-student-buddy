\# 🤖 Smart Student Buddy



An AI-powered student assistant built using Python, Streamlit, and Google Gemini AI.



\## 📌 Project Description



Smart Student Buddy helps students with their academic and college-related activities using Artificial Intelligence.



\## ✨ Features



\- 🤖 AI Doubt Solver

\- 📚 Study Planner

\- 📝 Notes Assistant

\- 🧠 Quiz Generator

\- 🎓 College Assistant



\## 🛠️ Technologies Used



\- Python

\- Streamlit

\- Google Gemini AI

\- Google GenAI SDK

\- Python-dotenv



\## 🚀 How to Run



1\. Clone the repository.

2\. Create and activate a virtual environment.

3\. Install the required packages.

4\. Add your Gemini API key to the `.env` file.

5\. Run the application.



```bash

streamlit run app.py
